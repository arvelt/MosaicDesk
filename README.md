# MosaicDesk

Windows向けのローカル自動モザイクアプリです。検出モデル・実行環境を含む単一の `MosaicDesk.exe` で動作します。通常実行時はオフライン・CPU処理です。

## ダウンロード

[リリースページ](https://github.com/arvelt/MosaicDesk/releases/latest)のAssetsから `MosaicDesk.exe` をダウンロードしてください。

## 日常の操作

1. フォルダ・PNGをドロップするか「フォルダを開く」「画像を開く」で読み込みます。前の一覧を置き換え、保存先を新しい入力元直下の `mosaicdesk_output` に戻します。
2. 読み込み時に検出し、原画に赤枠を表示します。画像名の下の「モザイク対象」、一覧直上の「全選択」「全解除」で対象を選びます。初期状態では全画像を選択し、実行後も選択を維持します。
3. 上部の「モザイクを付与」「メタ情報を削除（全体）」を設定して「実行」を押します。モザイクは選択した画像、メタ情報削除は一覧全体に適用します。例えば12枚中2枚を選択して両方オンなら、2枚をモザイク処理し、12枚すべてのメタ情報を削除して保存します。
4. 実行後は赤枠を外して保存結果を表示します。次の画像群を読み込んで続けて実行できます。処理トグルとモザイク設定は維持します。

PNG専用です。フォルダは直下のPNGだけを扱い、同じ元ファイルは重複追加しません。両方の処理がオフなら実行できません。別フォルダを混在させた場合は「出力先を変更」で共通の保存先を指定します。対象ファイル名の衝突や元画像の上書きは拒否し、自動連番は作りません。

## プレビューと任意の領域編集

画像をクリックするとプレビューを開きます。「前へ」「次へ」で続けて確認でき、プレビュー・原画・比較と倍率を切り替えられます。表示モードと倍率は画像を移動しても維持します。

手直しが必要なときだけ「領域を編集」を開きます。枠を選んで移動、角をドラッグしてサイズ変更、追加モードでドラッグして領域追加、削除・領域ごとのブロック幅変更ができます。UndoはCtrl+Z、RedoはCtrl+YまたはCtrl+Shift+Zです。「リセット」は全領域を消し、Undoで戻せます。

「編集を反映」は一覧へ領域設定を反映するだけで、出力ファイルを変更しません。出力を更新するのは上部の「実行」です。常に元画像と現在の領域設定から生成します。同じ設定で保存済みの出力は内容も照合して書き直しを避け、変更した画像だけ同名で更新します。

編集状態は `%LOCALAPPDATA%\MosaicDesk\edits.json` に保存します。メタ情報だけの処理でも領域設定は失いません。設定変更時は自動検出した領域を再検出します。手動で調整した領域は維持します。元画像の内容が変われば古い編集状態を復元しません。

## PNGメタ情報と設定

メタ情報削除は初期状態でオンです。tEXt・zTXt・iTXt・eXIfを除去し、parametersやprompt/workflowを残しません。検出なしの画像にも適用します。ICCプロファイルとDPIは保持し、削除がオフの場合は生成情報を保持します。

設定画面でブロック幅、余白、検出しきい値、乳首の検出、処理ログを変更できます。設定はEXE隣の `settings.json`、任意のログは出力フォルダ隣の `mosaicdesk_output.processing.json` に保存します。完成画像フォルダにはPNGだけを保存します。

検出対象はpenis・pussyと任意のnipple_fです。矩形検出の漏れ・誤検出はあり得るため出力を目視確認してください。解像度、対象外の画素、透明度を保存時に検証します。8bit以下の単一フレームPNGに対応し、16bit・複数フレームPNGは変更せずエラーにします。

## ビルドと検証

Windows x64 / Python 3.12で `build.ps1` を実行します。初回の依存関係・モデル取得にはインターネットが必要です。モデルのリビジョンとSHA256を固定し、仮想環境でテスト後に単一EXEへ梱包します。単一EXEは起動時に一時フォルダへライブラリとモデルを展開します。

`pytest test_local.py test_desktop.py -q` で入力・保存・メタデータ・領域編集・Undo/Redo・再編集・UIのテストを実行できます。`MosaicDesk.exe --check-ui` は一時フォルダと画面外のウィンドウを使う診断です。テスト画像は非性的な合成画像です。成人向けCG全般に対する検出精度を保証するものではありません。
