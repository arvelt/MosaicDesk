# MosaicDesk

Windows向けのローカル自動モザイクアプリです。検出モデル・実行環境を含む単一の `MosaicDesk.exe` で動作します。通常実行時はオフライン・CPU処理です。

## ダウンロード

[リリースページ](https://github.com/arvelt/MosaicDesk/releases/latest)のAssetsから `MosaicDesk.exe` をダウンロードしてください。

## 入力と処理

PNG画像またはフォルダを画面へドラッグ＆ドロップします。「画像を追加」では1枚・複数枚を選択でき、「フォルダを選ぶ」も利用できます。追加した画像は処理前から一覧に表示され、同じ元ファイルは重複登録しません。フォルダ入力は直下のPNGだけを追加します。PNG専用です。

「未処理の画像を一括処理」で未保存の画像をまとめて処理します。「この画像だけ処理」では1枚だけ処理できます。すでに保存済みの画像は、未処理画像の追加バッチでは更新しません。「一覧をクリア」で別の画像群に切り替えられます。

保存先は入力元直下の `mosaicdesk_output` です。「出力先を変更」で任意の共通フォルダを指定できます。別フォルダの画像が混ざる場合は、共通の出力先を選ぶまで保存を開始しません。別フォルダに同じファイル名がある場合は衝突を表示し、元画像の上書きや自動連番は行いません。完成画像フォルダにはPNGだけを保存します。

## 領域編集・再保存

「拡大・領域を編集」で、修正画像・原画・左右比較と表示倍率を切り替えられます。編集操作は修正画像側で行います。

- 領域を追加：追加モードでドラッグします。
- 選択・移動：枠または右側の領域一覧を選択し、枠をドラッグします。
- サイズ変更：選択した枠の角をドラッグします。
- 座標・サイズ・強度：右側でX・Y・幅・高さ・ブロック幅を変更し、「選択領域へ適用」を押します。
- 削除：「領域を削除」を押します。
- Undo / Redo：Ctrl+Z、Ctrl+YまたはCtrl+Shift+Zです。ボタンからも操作できます。
- リセット：現在の画像の全領域を消します。Undoで戻せます。

「この画像を保存・更新」で、元画像と現在の領域から再生成し、同名の出力PNGだけを更新します。他の画像には触れず、出力済み画像を加工元にしません。未保存の変更がある状態で戻ると、保存・破棄・キャンセルを選べます。

編集状態は `%LOCALAPPDATA%\MosaicDesk\edits.json` に保存します。同じ元画像を再度追加すると領域を復元します。元画像の内容が変わった場合は、古い編集状態を復元せず自動検出から開始します。元画像そのものは変更しません。

## PNGメタデータ

「PNGメタデータを削除」は初期状態でオンです。保存時にtEXt・zTXt・iTXt・eXIfを除去し、A1111/ForgeのparametersやComfyUIのprompt/workflowを残しません。検出なしの画像・個別保存・再編集時も適用します。ICCプロファイルとDPIは保持します。削除をオフにした場合は生成情報を保持します。

## 設定と対応範囲

設定画面でブロック幅・余白・検出しきい値・乳首の検出・任意の処理ログを変更できます。処理ログは出力フォルダの隣の `mosaicdesk_output.processing.json` に保存し、同じログファイルを更新します。設定はEXEの隣の `settings.json` に保存します。

自動検出は矩形で、対象はpenis・pussyと任意のnipple_fです。検出漏れ・誤検出はあり得るため、公開前に出力を目視確認してください。全領域を元画像から通常の画素処理でレンダリングし、保存前に解像度・対象外画素・透明度を検証します。領域が重なる部分は一覧で後の領域を優先します。8bit以下の単一フレームPNGに対応し、16bit・複数フレームPNGは元画像を変更せずエラーにします。

## ビルドと検証

Windows x64 / Python 3.12で `build.ps1` を実行します。初回の依存関係・モデル取得にはインターネットが必要です。モデルのリビジョンとSHA256を固定し、仮想環境でテスト後に単一EXEへ梱包します。単一EXEは起動時に一時フォルダへライブラリとモデルを展開します。

`pytest test_local.py test_desktop.py -q` で入力・保存・メタデータ・領域編集・Undo/Redo・再編集・UIのテストを実行できます。`MosaicDesk.exe --check-ui` は一時フォルダと画面外のウィンドウを使う診断です。テスト画像は非性的な合成画像です。成人向けCG全般に対する検出精度を保証するものではありません。
