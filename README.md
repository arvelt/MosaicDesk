# MosaicDesk

Windows向けのローカル自動モザイクアプリです。配布物は検出モデルを含む `MosaicDesk.exe` 一本です。Pythonの別途インストールやインターネット接続は不要です。

## ダウンロード

[リリースページ](https://github.com/arvelt/MosaicDesk/releases/latest)のAssetsから `MosaicDesk.exe` をダウンロードしてください。

## 使い方

アプリを起動し、PNGフォルダを画面へドロップして「モザイク処理を開始」を押します。完了後に画像をクリックし、修正画像・原画・左右比較を切り替えて確認します。設定画面でブロック幅・余白・検出しきい値等を変更できます。

完成画像は元フォルダの隣の `元フォルダ名-censored` に保存します。同名がある場合は連番を追加します。保存先には完成PNGだけを置きます。任意の処理ログはそのフォルダの隣に保存します。設定はEXEの隣の `settings.json` に保存します。

検出範囲は矩形です。対象はpenis・pussy、乳首は任意で追加できます。検出漏れ・誤検出はあり得るため、出力を目視確認してください。画像を生成AIで描き直さず、矩形内だけを通常の画素処理でモザイク化します。保存後に解像度・対象外画素・透明度を検証します。8bit以下の単一フレームPNGに対応し、16bit・複数フレームPNGは変更せずエラーにします。

## ビルド

Windows x64 / Python 3.12で `build.ps1` を実行します。初回の依存関係・モデル取得にはインターネットが必要です。モデルのリビジョンとSHA256を固定し、仮想環境でテスト後に単一EXEへ梱包します。通常実行時はオフライン・CPU推論です。

単一EXEは起動時に一時フォルダへ実行ライブラリ・モデルを展開します。終了時に通常は削除されます。ライセンス文・第三者著作権表示もEXE内に含め、アプリの「ライセンス」から閲覧できます。
